## 当前文档基线

本 Wiki 基于 2026 年 6 月 4 日检查的本地 Aether Workshop / MYCO Studio 源码、项目文档、配置和官网素材编写。它记录了从源码确认的用户可见行为，并谨慎标注隐藏或遗留模块。

## 每次发布应更新

当以下内容变化时，请更新 Wiki：

- 主标签或工具栏入口。
- 默认组件注册表。
- Capsule 编辑器行为。
- 云端角色、邀请或 API。
- 项目文件 schema。
- AI provider/model 行为。
- Arduino CLI、开发板或依赖流程。
- 隐藏/遗留模块变为可见或被移除。
