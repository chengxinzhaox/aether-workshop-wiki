## 本 Wiki 覆盖什么

本文档面向普通用户和进阶用户。普通用户可以按步骤完成硬件项目；进阶用户可以维护组件库、编写 Arduino 代码片段、管理 Capsule 和云端库。

- 安装 Aether Workshop，准备 Arduino CLI、开发板、端口、依赖和 API key。
- Home、Project、Library、Capsules、Setting 五个主入口。
- 可视化节点编辑、硬件映射、代码生成、上传、串口监视器、媒体播放和遗留/条件性的摄像头相关模块说明。
- 组件和 Capsule 的创建、编辑、历史、云端共享与项目覆盖。
- 项目评论、Pin、Change Log、History，以及 `.aew` 项目包结构。
- 云仓库创建、成员角色、邀请链接、push/pull、远端更新和 `.aetherlib` 导入导出。

如果源码中存在旧模块或隐藏入口，文档会明确说明，不会把它们写成当前默认可见功能。
