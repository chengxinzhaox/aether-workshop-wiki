## Current Documentation Baseline

This Wiki was prepared from the local Aether Workshop / MYCO Studio source tree inspected on June 4, 2026. It documents the user-visible app behavior confirmed from source, project docs, configuration, and reusable website assets.

## What to Update on Each Release

Update this Wiki when:

- Main tabs or toolbar actions change.
- Component registry defaults change.
- Capsule editor behavior changes.
- Cloud roles, invitations, or API endpoints change.
- Project file schema changes.
- AI provider/model behavior changes.
- Arduino CLI, board, or dependency workflows change.
- Hidden/legacy modules become visible or are removed.

## Suggested Release Note Format

```md
## Version X.Y.Z

- New:
- Changed:
- Fixed:
- Known issues:
- Documentation updates:
```
