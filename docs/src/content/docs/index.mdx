## What This Wiki Covers

This Wiki is written for normal users who want a reliable hardware-building flow and for advanced users who maintain libraries, write custom Arduino snippets, or manage shared cloud packages. It documents:

- Installing Aether Workshop and preparing Arduino CLI, boards, ports, dependencies, and API keys.
- The Home, Project, Library, Capsules, and Setting tabs.
- Visual graph editing, hardware mapping, code generation, upload, serial monitor, media playback, and legacy camera/face-detection support.
- Component and Capsule authoring, including source libraries, UI elements, private libraries, AI profiles, project overrides, and version history.
- Project comments, pins, change logs, snapshots, and saved `.aew` package structure.
- Cloud library creation, member roles, invitations, pushes, pulls, remote update handling, and package export/import.

Where the app source contains legacy or hidden modules, the docs say so explicitly instead of presenting them as first-class visible features.
